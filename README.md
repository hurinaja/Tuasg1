# 🌐 Sport Biodata Website

Website biodata interaktif berbasis React + TypeScript dengan tema olahraga.

---

## 🚀 Fitur Utama

* 🌙 Dark Mode & Light Mode
* 🌐 Multi Bahasa (Indonesia & English)
* 🏀 Tema Olahraga
* 🧭 Navbar Modern
* ⏳ Loading Screen
* 🎨 UI Modern (Tailwind CSS)
* 📧 Kontak langsung (Email & Instagram)
* ⚡ Animasi & Hover Effect

---

## 🛠️ Teknologi yang Digunakan

* React (Vite)
* TypeScript
* Tailwind CSS

---

## 📁 Struktur Project

```
src/
 ├── App.tsx
 ├── main.tsx
 └── components/
      ├── Navbar.tsx
      ├── Home.tsx
      └── Footer.tsx
```

---

## ▶️ Cara Menjalankan Project

1. Clone repository:

```
git clone https://github.com/USERNAME/NAMA-REPO.git
```

2. Masuk ke folder project:

```
cd biodata-hurin
```

3. Install dependencies:

```
npm install
```

4. Jalankan project:

```
npm run dev
```

5. Buka di browser:

```
http://localhost:5173
```
